Why Lambda instead of ECS/Fargate? The EC2 instance role lacked permissions for ECR, ECS, and CloudFormation. Lambda was accessible and required no container build pipeline. The agent logic runs identically — only the hosting layer differs.
Why moto instead of real DynamoDB? No dynamodb:CreateTable or dynamodb:PutItem permissions on the instance role. moto provides a full in-memory DynamoDB implementation with zero AWS permissions required.
